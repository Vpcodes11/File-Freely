Frequently asked questions

Is FileFreely a free ProperSoft (ProperConvert) alternative?

Every file gets a free preview and a free download of its first 10 transactions, so you can test the import before paying. Full files cost $5 for one file, $9 for 7 days or $19 a month.

Are my bank statements uploaded?

No. FileFreely reads the file with JavaScript in your browser. The transactions never reach our servers.

Will the QBO file import into QuickBooks?

Yes. The QBO file uses a bank ID that QuickBooks Desktop and QuickBooks Online accept, and you can set the account type and number before downloading.

What if my statement is a scan?

FileFreely needs a PDF with selectable text, such as a statement downloaded from online banking, or a CSV export. For scans you need an OCR tool.
