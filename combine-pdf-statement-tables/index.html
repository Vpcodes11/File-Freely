Combine PDF Statement Tables in Excel

To combine tables from several pages of a digital PDF statement, extract the pages that share a header, keep that header once, and export the rows to one Excel sheet or CSV. A source-page column lets you find each row in the original statement.

Open the PDF to Excel converter Download the sample PDF

How to combine the statement pages

  1. Choose a PDF with selectable text. Find the first and last pages containing the same table layout.
  2. In the converter, pick Combine repeating statement tables. Set the header row. If the statement title occupies the first extracted row, the table header may be row 2. Use the separate-page preview to check.
  3. Extract the rows, review the combined preview, and compare at least one row from each source page with the original. Download Excel for a workbook or CSV for import.

Worked example with a two-page PDF

The sample has a title on each page, a table header on row 2, and three invoice lines across two pages. Select pages 1–2 and header row 2. The combined export has three data rows, one header, and a source-page column.

What if the headers differ?

Statement mode stops when a selected page has different headers or a different column count. Exclude cover pages and unrelated tables, or switch to separate-page export for layouts that vary. If the headers look identical on paper, try changing the column-gap setting and inspect the extracted header cells.

Can I combine a scanned statement?

An image-only scan needs a selectable text layer first. If you cannot select individual words in a PDF viewer, ask for the original digital statement or use OCR before importing. Check quantities and decimals against the source after OCR.

How to repeat this next month

For a recurring vendor layout, choose Remember layout, header row, and column gap on this browser. The next statement can reuse those settings. The selected PDF and extracted data stay in your browser during processing. Confirm the page range again because the number of pages can change.
