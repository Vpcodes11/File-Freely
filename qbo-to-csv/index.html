How to convert QBO, QFX or OFX to CSV

  1. Drop your file in the box above. The converter finds the date, description and amount columns.
  2. Check the column choices and the preview. Fix the date format or flip signs if needed.
  3. Choose the output and account type, then download.

Import it into Excel or Google Sheets

  1. Open the CSV in Excel, Numbers or Google Sheets (File > Import in Sheets).
  2. Dates are written as YYYY-MM-DD so every spreadsheet reads them the same way.
  3. Edit or categorise lines as needed, then save or import the sheet wherever you need it.

Why use this converter

QBO, QFX and OFX files are plain text but hard to read. This tool lists every transaction (date, payee, amount, memo, check number) so you can check what a bank file contains, edit it in a spreadsheet, or move it into an app that wants CSV.

Frequently asked questions

Can I convert QFX to QBO here as well?

Yes. Choose QBO in the Save as list, or use the QFX to QBO page.

Are transaction IDs kept?

Yes. The original FITIDs are kept when you save back to QBO, QFX or OFX.

Does it handle OFX 2 (XML) files?

Yes, both the older SGML style and XML style are read.

Is my file uploaded?

No.
