How to convert PDF statement to Xero CSV

  1. Drop your file in the box above. The converter finds the date, description and amount columns.
  2. Check the column choices and the preview. Fix the date format or flip signs if needed.
  3. Choose the output and account type, then download.

Import it into Xero

  1. In Xero, go to Accounting > Bank accounts and open the account.
  2. Choose Manage account > Import a statement and upload the CSV.
  3. Match the columns: *Date, *Amount, Payee, Description and Reference are named the way Xero expects. Pick the same date format you chose above.
  4. Reconcile the imported lines.

Why use this converter

If your bank feed has gaps, or a client sends PDF statements, retyping lines into Xero takes hours. This tool reads the PDF in your browser and writes a CSV with the column names Xero expects (*Date, *Amount, Payee, Description, Reference), with the date format you choose for UK, Australian, New Zealand or US organisations.

Frequently asked questions

Should I use the CSV or OFX?

OFX imports without column mapping. CSV lets you edit lines in a spreadsheet before importing. Both work in Xero.

Which date format should I choose?

Use DD/MM/YYYY for UK, Australian and New Zealand organisations and MM/DD/YYYY for the US.

Does it work for credit cards?

Yes. Tick Flip signs if purchases come out positive.

Is my statement uploaded?

No.
