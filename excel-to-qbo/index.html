How to convert Excel to QBO

  1. Drop your file in the box above. The converter finds the date, description and amount columns.
  2. Check the column choices and the preview. Fix the date format or flip signs if needed.
  3. Choose the output and account type, then download.

Import it into QuickBooks Desktop

  1. In QuickBooks Desktop, open the bank or credit card account you want to fill. If it is connected to a live bank feed, deactivate the feed first (Banking > Bank Feeds > Bank Feeds Center).
  2. Go to File > Utilities > Import > Web Connect Files and choose the .qbo file.
  3. When asked, pick Use an existing QuickBooks account and select the account. QuickBooks shows the bank name from the Bank ID (Wells Fargo for the default 3000). That label does not matter.
  4. Review and add the transactions in the Bank Feeds Center.

Why use this converter

Bookkeepers often receive transactions in Excel: a client spreadsheet, a petty cash log, or a bank export saved as .xlsx. QuickBooks Desktop cannot import those into a bank register. This tool reads the first worksheet, finds the header row, and turns each row with a valid date and amount into a QBO transaction.

Frequently asked questions

Which worksheet is used?

The first worksheet in the file. Move the transactions to the first sheet if they are elsewhere.

My dates show as numbers in Excel. Is that a problem?

No. Excel date serial numbers are converted automatically.

Can I add categories?

QBO files carry only date, payee, amount, memo and check number. To post to specific accounts, use the IIF format instead.

Is my spreadsheet uploaded?

No. Everything happens in your browser.
