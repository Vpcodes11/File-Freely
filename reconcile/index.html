How to reconcile a supplier statement against a ledger

Compare the supplier’s invoice references and signed balances with an accounts payable export for the same supplier and cutoff. For an open-items statement, compare balances still outstanding as of that date. For a period statement, use ledger activity from the same dates. Review missing items before changing the ledger.

How does FileFreely handle duplicates?

If a reference appears more than once on either side, the report keeps all source rows for review. Suggested matches use the same signed amount and transaction type with dates within three days, and require confirmation.

What does an amount mismatch look like?

If the supplier lists INV-104 at $420 on PDF page 2 and the ledger lists it at $400 on row 18, the signed difference is +$20. The report shows both source locations and leaves the item open.

Can I reconcile a scanned PDF?

Use a digital PDF with selectable text, CSV, or XLSX for the statement. If you only need to export tables first, use PDF to Excel and CSV.
