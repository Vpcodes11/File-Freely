Recurring Supplier Statement Layout Setup

The $99 one-time setup covers one recurring supplier statement layout and one matching accounts payable export format. It’s designed for bookkeepers and AP teams that receive the same format each month.

Request setup

What the setup includes

  • A reusable mapping for one supplier layout and one AP export, including the document reference, signed amounts, dates, and transaction types where available.
  • Documented table settings for the relevant pages, header row, and column spacing.
  • A worked Excel reconciliation report with source references and a checklist you can follow next month.

Which files fit this setup?

Use a selectable-text PDF, CSV, or XLSX statement and a CSV or XLSX ledger for the same supplier, currency, cutoff, and amount basis. The setup covers repeat use of the configured layout. A supplier redesign or a different ledger export may need a separate mapping.

How documents are handled

The self-service reconciliation runs in your browser. For a layout setup, agree on a secure way to share redacted samples before providing documents.
