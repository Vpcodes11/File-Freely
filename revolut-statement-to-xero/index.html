Revolut Statement to Xero Converter

Download your transactions from Revolut, drop the file here and get a file Xero imports cleanly. The converter knows the Revolut export layout, so the date, payee and amount columns are picked for you.

🔒 Your file is read in your browser and never uploaded. The first 10 transactions are free; full files start at $5.

1. Download your transactions from Revolut

In the Revolut app, open the account, tap Statement, choose Excel (CSV) and the period, and export.

2. Convert the Revolut file

Revolut exports have Type, Product, Started Date, Completed Date, Description, Amount, Fee, Currency, State and Balance columns, with dates written year first. The converter uses Started Date, Description and Amount. Fees are listed separately by Revolut; add them as their own lines if you need them in your books.

  1. Drop the file in the box above.
  2. Check the preview: dates, payees and amounts should match your statement.
  3. Choose the output (Xero is selected; QBO, QFX, OFX, IIF and QIF are also available) and download.

3. Import it into Xero

  1. In Xero, go to Accounting > Bank accounts and open the account.
  2. Choose Manage account > Import a statement and upload the CSV.
  3. Match the columns: *Date, *Amount, Payee, Description and Reference are named the way Xero expects. Pick the same date format you chose above.
  4. Reconcile the imported lines.

Frequently asked questions

My Revolut account has several currencies. What do I do?

Export one currency at a time and set the matching currency in the output settings.

Should I import declined or reverted lines?

No. Remove lines whose State is not COMPLETED before converting, or delete them during review.

Is my bank data uploaded?

No. The file is read and converted by your browser. Nothing is sent to FileFreely or anyone else.

How much does it cost?

The preview and the first 10 transactions of every file are free. Full files cost $5 for one file (24 hours), $9 for a 7-day pass or $19 a month.
