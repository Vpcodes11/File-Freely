Wise Statement to Xero Converter

Download your transactions from Wise, drop the file here and get a file Xero imports cleanly. The converter knows the Wise export layout, so the date, payee and amount columns are picked for you.

🔒 Your file is read in your browser and never uploaded. The first 10 transactions are free; full files start at $5.

1. Download your transactions from Wise

In Wise, open the balance, choose Statements and reports, pick the period and download the CSV statement.

2. Convert the Wise file

Wise statements have TransferWise ID, Date, Amount, Currency, Description, Payment Reference, Running Balance and exchange columns. The converter uses Date, the signed Amount and Description, and keeps the Wise ID so repeated imports can be spotted.

  1. Drop the file in the box above.
  2. Check the preview: dates, payees and amounts should match your statement.
  3. Choose the output (Xero is selected; QBO, QFX, OFX, IIF and QIF are also available) and download.

3. Import it into Xero

  1. In Xero, go to Accounting > Bank accounts and open the account.
  2. Choose Manage account > Import a statement and upload the CSV.
  3. Match the columns: *Date, *Amount, Payee, Description and Reference are named the way Xero expects. Pick the same date format you chose above.
  4. Reconcile the imported lines.

Frequently asked questions

I have balances in several currencies. Can I convert them all at once?

Download one statement per currency and convert each with the matching currency set in the output settings.

Are Wise fees included?

Wise shows fees in a separate column. If you need them in your books, add them as separate lines.

Is my bank data uploaded?

No. The file is read and converted by your browser. Nothing is sent to FileFreely or anyone else.

How much does it cost?

The preview and the first 10 transactions of every file are free. Full files cost $5 for one file (24 hours), $9 for a 7-day pass or $19 a month.
