How to convert PDF statement to QFX

  1. Drop your file in the box above. The converter finds the date, description and amount columns.
  2. Check the column choices and the preview. Fix the date format or flip signs if needed.
  3. Choose the output and account type, then download.

Import it into Quicken

  1. In Quicken for Windows, go to File > File Import > Web Connect (.QFX) File. On a Mac, use File > Import and choose the Web Connect file.
  2. Choose Link to an existing account and select the account the transactions belong to.
  3. If the account is set up for Express Web Connect or Direct Connect, Quicken may ask you to deactivate online services for that account first.
  4. Accept the downloaded transactions in the register.

Why use this converter

Quicken can only download a limited history from most banks. Older months are usually available only as PDF statements. This converter pulls the dated transaction lines from each page and writes a QFX file that Quicken imports like a download.

Frequently asked questions

Will it work with credit card statements?

Yes. Set the account type to Credit card. If purchases show as positive amounts, tick Flip signs.

What about scanned statements?

They need OCR first. Download the PDF from online banking if you can.

Can I convert several months at once?

Convert each statement separately, or combine the PDFs first with our Merge PDF tool.

Is my statement uploaded?

No.
